# processedResume 字段提取兜底说明

> **适用文件：** `src/utils/extractProcessedResumeField.js`  
> **使用场景：** `background.js` 批量上传时，从大模型返回文本中解析结构化字段

---

## 一、推荐语

1. **标准格式 + `---` 分隔线**（推荐语取到 `---` 前，可多行）

   ```text
   **推荐语**:候选人具备相关经验
   ---
   ```

2. **缺少分隔线 `---`**（推荐语取到换行，不含正文）

   ```text
   **推荐语**： 虽无直接行业经验，但学习能力强，可作为潜力人选关注。
   简历正文内容
   ```

   **结果：** 只取推荐语一行，不含「简历正文内容」

3. **缺少 `---` 且无换行**（推荐语截断至 100 字）

   ```text
   **推荐语**： 很长的话……简历正文紧随其后（同一行）
   ```

   **结果：** 最多取前 100 字，避免把粘连的正文全部当作推荐语

---

## 二、通用字段（姓名 / 期待薪资 / 年龄 / 居住地）

4. **标准 markdown + 中文冒号**（理想格式）

   ```text
   **期待薪资**： 35-45K
   **年龄**： 32
   **居住地**： 上海
   姓名： 张三
   ```

5. **英文冒号**（大模型偶发输出）

   ```text
   **期待薪资**: 30k-50k
   **居住地**: 上海
   ```

6. **句号分隔**（中英文 `.` / `。`）

   ```text
   期待薪资. 面议
   **年龄**。 35
   ```

7. **混用标点 + 部分无 markdown 粗体**

   ```text
   姓名： 陈静
   **期待薪资**: 30万/年
   ```

8. **多余空白 + 中文句号**

   ```text
   **候选人姓名** ：  赵强
   **期待薪资** 。 25-30K
   ```

9. **markdown 粗体 + 空格分隔**（无冒号，仅 `*` 标签）

   ```text
   *期待薪资* 30k-50k
   ```

   > 空白分隔仅对带 `*` 的 markdown 标签生效

10. **markdown 粗体残缺**（`*` 不对称）

    ```text
    *期待薪资*:30k-50k
    年龄**:32岁
    期待薪资*:30k-50k
    **居住地:上海（缺闭合 **）
    *推荐语:xxx（缺闭合 *）
    ```

11. **行内带 `---`**（取值不含分隔线）

    ```text
    *期待薪资*:30k-50k ---
    ```

    **结果：** 只取 `30k-50k`

12. **纯文本标签**（无 markdown 粗体）

    ```text
    姓名： 张三
    期待薪资: 30k-50k
    ```

---

## 三、优势标签

13. **标准 markdown + 冒号**

    ```text
    **优势标签**:团队管理，投资人关系
    ```

14. **优势标签无 markdown 粗体**

    ```text
    优势标签:团队管理，投资人关系，市场拓展
    ```

15. **宽松前缀**（标签名后可带说明文字）

    ```text
    优势标签如下： Java, Spring
    ```

---

## 四、异常兜底

16. **API 返回 null / 空文本** → 返回空字符串 `""`，不报错

17. **格式残缺**（仅部分字段可提取）→ 能识别的字段正常提取，其余返回 `""`

18. **全部字段匹配失败** → 返回 `""`，控制台输出 `warn` 日志

---

## 五、大模型标准输出格式（参考）

```text
**优势标签**:团队管理，投资人关系
**期待薪资**:30k-50k
**年龄**:32岁
**居住地**:上海
**推荐语**:候选人具备相关经验
---
```

## 六、各字段提取配置

| 字段 | 标签名 | 特殊规则 |
|------|--------|----------|
| 姓名 | `候选人姓名` / `姓名` | 截止：换行 / 回车 / `---` / 文末 |
| 优势标签 | `优势标签` | 宽松前缀 |
| 推荐语 | `推荐语` | 独立三分支逻辑（见第一节） |
| 期待薪资 | `期待薪资` | 默认单行规则 |
| 年龄 | `年龄` | 默认单行规则 |
| 居住地 | `居住地` | 默认单行规则 |

---

## 七、提取优先级说明

1. 每个字段按多种标签格式依次尝试，任一匹配成功即返回
2. 分隔符优先匹配标点（`:` `：` `.` `。`），markdown 标签才尝试空格分隔
3. 单行字段在换行、`---` 或文末处停止取值
4. 推荐语单独处理，不按普通单行字段逻辑
